# 飞洋海洋运输管理系统项目说明与使用手册

## 一、系统定位

飞洋海洋运输管理系统（FeiYang OTMS）面向中小型海运货代与航运企业，覆盖港口/船舶/航次/订舱/集装箱/提单/运价/往来账单全业务链，内置 ISO 6346 箱号校验、航次装载预检、滞箱费阶梯计费、四类风险预警，并预留 REST 接口供 ERP/单一窗口等外部系统对接。零依赖技术栈（Python 标准库 + SQLite WAL），单机即可运行。

## 三、12 页面逐页说明

1. **工作台**：9 项 KPI（航次/订舱/在途箱/应收/逾期/滞箱费预估等）+ 待办与公告。
2. **船舶管理**：船舶档案（名称、IMO 7 位唯一、载重、箱位 TEU），增删改查。
3. **航次管理**：航次计划与四态推进（计划→离港→到港→闭环，可取消）；超载禁止离港；关联订舱列表。
4. **订舱管理**：创建订舱（选航次/客户/箱型/箱量）自动装载预检，超载 422；状态推进 装船→开船→交付，联动箱货。
5. **提单管理**：草稿→签发→交单/电放；按订舱生成，登记通知方。
6. **箱货管理**：集装箱全生命周期（空箱→装货→在途→卸货→返空），ISO 6346 校验位强校验，在途禁改封号，滞箱费列实时估算。
7. **运价管理**：港口对×箱型运价维护与有效期；运价查询弹窗按 (起运港， 目的港， 箱型， 箱量) 试算整箱报价。
8. **往来单位**：客户/船公司/代理档案及其账单视图。
9. **账单结算**：应收应付账单、部分/全额/超额截断结算，自动生成资金流水；逾期筛选。
10. **货物跟踪**：输入订舱号、提单号或集装箱箱号，查询全链路时间线（订舱→装船→开船→到港→卸货→交付）。
11. **风险预警**：四类风险（滞箱超期/账单逾期/航次超载/运价到期）一键扫描，去重后处理闭环。
12. **系统管理**：用户与角色、API Key 生成（fyo_ 前缀）、业务参数（免箱天数/滞箱费率）、日志与增量同步。

## 四、典型流程

**新订舱出货**：船舶管理确认船期 → 航次管理新建航次 → 订舱管理创建订舱（装载预检）→ 箱货管理录入集装箱 → 订舱"装船"联动箱在途 → 航次"离港" → 订舱"交付"联动箱卸货 → 提单签发。

**应收结算**：账单管理新建应收 → 客户付款 → 账单结算（部分或全额，超额自动截断）→ 流水自动生成 → 风险页逾期自动消除。

**外部对接**：系统管理生成 API Key（如 fyo_…）→ 外部系统以 X-Api-Key 调用 REST 接口（创建订舱、查询跟踪等）；支持 Idempotency-Key 幂等与增量同步协议。

## 五、口径说明

- 所有金额以分（整数）存储，显示层再除以 100，避免浮点误差。
- TEU 折算：20ft=1.0，40/45ft=2.0；装载预检按订舱箱量×折算累计与船舶箱位比较。
- 滞箱费：占用天数 − 免箱天数（默认 4），按阶梯 (1-4 天 200 元/天，5-8 天 400 元/天，9 天起 800 元/天) 计费。

## 六、部署运维

- 本地运行：`python backend/server.py`（env OY_PORT=8031、OY_DB=data/feiyang.db、OY_PREFIX=/ocean）。
- 线上部署：nginx 前缀 /ocean/ 反代 + systemd 服务 feiyang-otms；首次启动自动建库与种子数据。
- 备份：SQLite 单文件 data/feiyang.db，直接冷备即可。
